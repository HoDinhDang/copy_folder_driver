⚙️ Cấu hình Google OAuth 2.0 Credentials

×

Để ứng dụng kết nối trực tiếp đến Google Drive của bạn, bạn cần tạo một OAuth Client ID (Web Application) trên Google Cloud Console.

  1. Vào Google Cloud Console API & Services.
  2. Tạo project mới hoặc chọn project có sẵn, bật Google Drive API.
  3. Vào mục Credentials > Create Credentials > OAuth Client ID.
  4. Chọn loại Web application.
  5. Tại mục Authorized redirect URIs, thêm:
    http://localhost:3000/api/auth/google/callback
  6. Dán Client ID và Client Secret vào bên dưới:

Cách 1: Triển khai Web App lên Cloud Miễn Phí (Khuyên dùng - Render / Railway)

Trang web này đã được tích hợp sẵn render.yaml và Dockerfile để bạn đưa lên Cloud chỉ trong 2 phút:

  1. Đưa mã nguồn thư mục này lên GitHub cá nhân của bạn.
  2. Đăng nhập vào Render.com (miễn phí).
  3. Chọn New Web Service > Chọn GitHub repo vừa tạo.
  4. Tại mục cấu hình môi trường (Environment Variables), thêm GOOGLE_CLIENT_ID và GOOGLE_CLIENT_SECRET.
  5. Bấm Deploy! Bạn sẽ có một đường link web cá nhân (ví dụ: https://my-drive-copier.onrender.com). Khi đó bạn bấm copy rồi tắt máy tính đi ngủ, máy chủ Render sẽ tự động chạy ngầm cho đến khi xong toàn bộ dữ liệu!

Cách 2: Google Apps Script (100% Máy chủ Google, Không cần server riêng)

Chúng tôi đã đính kèm sẵn mã nguồn tại thư mục google-apps-script/:

  1. Truy cập Google Apps Script > Bấm New project.
  2. Copy nội dung file google-apps-script/Code.gs vào trình soạn thảo.
  3. Bấm Deploy > New deployment > Chọn type Web App.
  4. Chọn "Execute as: Me" và "Who has access: Anyone".
  5. Bạn sẽ nhận được ngay 1 link trang web chạy trực tiếp 100% trên server của Google!
